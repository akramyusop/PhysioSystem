Strategic Opportunity & Core Value Proposition Slide 2 / 11

The Clinic-to-Home Adherence Gap

Why traditional physiotherapy outpatient care fails and how PhysioSystem solves it.

⚠️ The Clinical Challenges
  • • 70% Home Drop-off: Patients abandon paper handouts due to lack of visual guidance and engagement.
  • • Doctor Workflow Friction: Manually typing sets, reps, and hold times per patient burns valuable clinical consultation hours.
  • • No Objective Recovery Telemetry: Clinicians rely on vague patient memory rather than measured ROM & pain data.
Result: Delayed recovery, recurrent re-injury, and clinical staff burnout.
✨ The PhysioSystem Breakthrough
  • • 1-Click Evidence-Based Protocols: Pre-validated clinical regimens populate in 1 second; doctors can create and store custom protocols.
  • • Gamified Canvas & Visual Library: Interactive hold timers, rep counters, and video guides transform rehab into an engaging habit.
  • • Closed-Loop Telemetry & Analytics: Automated range-of-motion (ROM) trajectories, pain curves, and urgent nurse flags.
Result: +85% adherence rate, halved doctor prescription time, and quantifiable recovery outcomes.
Corporate Goal: Standardize orthopedic tele-rehabilitation across university clinics & hospitals. PhysioSystem v1.0

Engineering Governance Slide 10 / 11

Technology Stack & Git Collaboration Blueprint

Engineered to eliminate merge friction across a 6-engineer graduate software project.

Enterprise Technology Stack

Backend Core Rust (Axum 0.7 + SQLx)
Frontend UI React 18 + TypeScript + Vite
Database Engine SQLite (ACID Compliant)
Dev Bridge Server Node.js `node:sqlite` fallback

Modular Git Branching Governance

  • ✓ Isolated Module Folders: Each engineer owns strictly 1 frontend folder and 1 backend Rust file.
  • ✓ Feature Branches: feat/mod1 through feat/mod6 prevent concurrent PR collisions.
  • ✓ Immutable Migrations: 001_init.sql is locked; new schema additions require incremental scripts.
  • ✓ Build Validation: Every feature passes tsc && vite build with 0 errors before merging.
